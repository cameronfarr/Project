# Project
In this repository, we are combining the front-end and back-end work for our Software Project Management class's group project.
This group contains Elijah Giusto as our leader, Abass Diaby, Cameron Farr, Garyah Fumbah, and Ella Goode.
Functional requirements: 
- Input of General Information
Project description
Project manager or owner
Add and Remove team members
Add and Update risks and risk Status
- Requirement management
Add, edit or delete functional and nonfunctional requirements
Store these requirements in a structured format
- Track Effort
Input the hours by day or week for: Requirements analysis, Design, Coding, Testing, Project Managements
These hours will be tracked by requirement and team member
Calculate totals automatically
- Reporting
Display
Total hours by category
Total Hours per requirement
Then, generate daily and weekly reports
- Analytics
Providing insights on the most time-consuming tasks and track progress
