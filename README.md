## How to Run

Open `HtmlPage.html` in a web browser. The project is a static HTML/CSS/JavaScript prototype and does not require a server, database, or installation step.

Data is stored in the browser using `localStorage` under the key `spmTrackerStateV1`. Use the Reset Data button in the app to clear the saved project data for a fresh demo.

## Implemented Features

- General project setup with project description and owner/project manager.
- Team member management with add and remove support.
- Risk management with add, edit, status update, and delete support.
- Functional and non-functional requirement management with add, edit, status update, delete, and structured storage.
- Effort tracking by requirement, team member, category, hours, and daily or weekly period.
- Automatic totals for Requirements Analysis, Designing, Coding, Testing, and Project Management.
- Total effort reporting per requirement.
- Daily and weekly report summaries.
- Analytics for most time-consuming requirement, most time-consuming category, highest effort team member, effort by team member, and requirement completion.
- Persistent browser storage so entries remain after refreshing the page.
- Responsive layout for desktop and narrow screens.
